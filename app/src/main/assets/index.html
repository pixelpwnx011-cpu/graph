Welcome to GeoGraph Teach

An offline graphing & geometry toolkit built for the classroom smart board.

📊

2D & 3D Graphing

Plot any equation — y=f(x), implicit relations, polar, parametric, or 3D surfaces z=f(x,y) — in one workspace. Switch between 2D and 3D any time.

📐

Coordinate Geometry

Tap to plot points, measure distance (including from the origin), midpoint, slope and polygon area.

🌀

Trigonometry

Drag the unit circle and watch all six trig ratios trace out live on a synced graph.

💡 Tip: turn on Show Labels in the sidebar to display the abscissa, ordinate, quadrants and coordinates for every point — great for teaching the basics.

Equations

Type naturally — the app auto-detects the form: y=sin(x), x=y^2, r=2cos(θ), x^2+y^2=25, x^2+y^2<25, or x=cos(t), y=sin(t). Use |x| for absolute value and mod(x,n) for modulo.

✏️ Draw / Enter Points → Equation

Tap Place Points, then tap the graph to mark points (or type coordinates below). Pick a curve type and generate its equation.

Surfaces z = f(x, y)

Supports |x| absolute value, mod(x,n), and Iverson brackets {condition} (1 where true, 0 elsewhere — chain {a}{b} for AND) to carve out regions. The letter t is reserved for the animation clock below.

Parametric Curves x(t), y(t), z(t)

Draw a 3D curve traced out as t sweeps from t₀ to t₁ — e.g. a polar curve r(θ) becomes x=r·cos(t), y=r·sin(t), z=0.

t = 0.00

Drag with one finger to rotate. Pinch (or scroll) to zoom. Tap a coloured ball on the corner gizmo to snap to that view — just like Blender's viewport gizmo.

Coordinate Geometry

Tap the plane to add points A, B, C… Drag any point to move it, or type exact coordinates below. Once you have 3+ points, tap point A again (or press "Close Polygon") to join the shape into a closed polygon.

When on, every point you place or drag rounds to the nearest grid line shown on the axes.

3D Trig Curves

The default helix is a point moving around the unit circle with a third axis added for elapsed angle — this is why circular motion produces sine and cosine waves. Drag the unit circle back in 2D mode and switch here to see the marker travel along the coil. Add, edit, or remove curves below to explore others.
